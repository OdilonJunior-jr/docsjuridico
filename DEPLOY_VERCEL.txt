DEPLOY V1.11

1. Substitua os arquivos do repositório GitHub pelos desta versão.
2. Faça commit/push.
3. A Vercel fará o redeploy automaticamente.
4. Supabase não precisa ser recriado se já está funcionando.
5. Para teste do OCR, nenhuma variável nova é obrigatória.
6. Opcional para uso mais estável: configure OCRSPACE_API_KEY na Vercel.

Ao gerar, o sistema cria automaticamente:
- Procuração .docx
- Procuração .pdf
- Declaração de Hipossuficiência .docx
- Declaração de Hipossuficiência .pdf
